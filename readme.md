# 🏡 Housing Trends Web Application

## 📌 Project Overview

The **Housing Trends** application is a Flask-based web application that provides comprehensive analysis and visualization of housing market data. It helps users understand market trends, price fluctuations, and key insights through a simple, interactive, and user-friendly interface.

---

## 🎯 Objectives

- Analyze housing market trends and price fluctuations.
- Identify key factors influencing property values.
- Compare housing patterns across different regions.
- Evaluate market demand and economic indicators.
- Provide meaningful business insights using structured data dashboards.

---

## 🛠️ Tools & Technologies

- Python
- Flask
- HTML5
- CSS3
- Pandas
- Render (Live Deployment)

## 📊 Tableau Dashboard

The interactive Tableau Dashboard provides a visual representation of the housing market data, enabling users to analyze trends and make data-driven decisions.

### Dashboard Highlights

- 📈 Average House Price Analysis
- 🏠 House Distribution by Bedrooms
- 📍 Location-wise Price Comparison
- 🏗️ House Condition & Grade Analysis
- 📅 Renovation and Construction Year Trends

---

## 📖 Tableau Story

The Tableau Story presents a sequence of visualizations that explain the housing market analysis in a logical flow.

### Story Covers

1. Housing Market Overview
2. Price Distribution Analysis
3. Location-wise Trends
4. Property Features Analysis
5. Key Business Insights and Conclusions

The story helps users understand the complete analysis step by step using interactive visualizations.
